# Omarchy Arcana — Visual Grammar

## Core Statement

**Order surrounding mystery.** The deterministic frame represents the system; the central illustration represents the archetype.

## Locked Card Format

- Canvas: 1200 × 2100 pixels
- Aspect ratio: 4:7
- Color mode: RGB
- Illustration viewport: 1032 × 1548 pixels
- Outer structure: paired graphite registration frames
- Active divider: card-specific semantic accent
- Header: Roman numeral, domain, workspace state, cursor-sigil
- Footer: traditional title, system interpretation, deck identifier

## Approved Header Sigil

The shared mark is a cursor-sigil rather than a tiled-window symbol:

- horizontal command line;
- diamond-shaped focus boundary;
- central semantic-color node;
- descending registration stem;
- brass terminal point.

It must remain small and subordinate to the Roman numeral. Four equal panes are prohibited because they resemble the Windows logo.

## Typography

- Roman numerals and card names: high-contrast serif
- System labels, states, and deck identifiers: monospaced sans
- Traditional tarot title remains primary
- System interpretation remains secondary
- All typography is applied deterministically; generated illustration layers contain no lettering

## Canonical Palette

| Role | Value | Use |
|---|---|---|
| Base | `#090b0c` | Card field and frame |
| Ivory | `#d8d3c7` | Primary typography and luminous structure |
| Muted | `#777771` | Metadata and secondary registration marks |
| Focus | `#62d6df` | Active command, illumination, connection |
| Brass | `#b78b48` | Sparse material and registration detail |
| Fault | `#d66a3d` | Failure, rupture, destructive state |

Saturation remains a limited budget. Accent color should generally occupy only a small fraction of the illustration.

## Illustration Language

- charcoal-paper and restrained halftone texture;
- graphite-black negative space;
- cool ivory architectural geometry;
- fine technical construction lines;
- restrained phosphor bloom and scanline grain;
- figures treated as operators, pilgrims, architects, or system entities;
- strong thumbnail silhouettes;
- generated source art contains no readable text, numerals, borders, logos, or watermarks.

## Symbolic Translation

Desktop references must function as symbols rather than props. Prefer:

- tiled planes as architecture;
- cursors as stars, sparks, or points of will;
- terminal panes as lanterns, altars, and thresholds;
- package seals as pentacles;
- command rods as wands;
- caret-blades as swords;
- signal vessels as cups;
- process and workspace states as marginal notation.

Avoid generic cyberpunk skylines, Matrix rain, random circuitry, excessive neon, literal screenshots, and laptops used as shorthand.

## Approved Visual-Grammar Cards

### I — The Magician / The Operator

Tests iconic identity, symbolic density, command, and the four-system-instrument correspondence.

### IX — The Hermit / Focus Mode

Tests negative space, solitude, restrained illumination, and quiet system architecture.

### XVI — The Tower / System Failure

Tests rupture, motion, destructive-state color, and catastrophic scale without abandoning the deck’s engineered geometry.
