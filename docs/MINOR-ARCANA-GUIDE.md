# The Omarchy Arcana

## Minor Arcana Guide

The four suits describe activity inside the Sovereign Desktop. Their traditional elemental roles remain intact while their system titles provide a second interpretive language.

## Wands · Execution / Fire

Commands, creative ignition, launching, building, automation, ambition, and directed will.

| Rank | System lens |
|---|---|
| Ace | Ignition point; a new command becomes possible |
| Two | Vector choice; selecting a direction |
| Three | Launch sequence; effort begins to travel outward |
| Four | Stable build; a working structure worth celebrating |
| Five | Competing processes; friction among active wills |
| Six | Successful deploy; visible recognition and momentum |
| Seven | Defended position; maintaining a chosen direction |
| Eight | Rapid execution; multiple actions moving cleanly |
| Nine | Persistent process; resilience near exhaustion |
| Ten | Workload saturation; execution exceeds healthy capacity |
| Page | Spark / Explorer; curiosity becoming action |
| Knight | Launcher; forceful movement and appetite for experience |
| Queen | Creative Integrator; confident generative command |
| King | Director of Will; mature direction and sustained vision |

## Rank Progression

Across every suit:

- **Ace** introduces the suit’s undivided potential.
- **Two** creates polarity, choice, or exchange.
- **Three** develops the first working structure.
- **Four** stabilizes it.
- **Five** introduces disruption.
- **Six** restores movement or relationship.
- **Seven** tests judgment and commitment.
- **Eight** intensifies the suit’s process.
- **Nine** approaches fulfillment while revealing its cost.
- **Ten** completes and exceeds the cycle.
- **Page** learns the suit.
- **Knight** moves through it.
- **Queen** internalizes and sustains it.
- **King** directs and governs it.
